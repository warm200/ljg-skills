# 周报

把一周里各个 ljg 技能写下的笔记放在一起看：用户这周在想什么，想法和上周比怎么变了。

数据都在用户的 MCP 记忆服务器里。读写规则见本目录 `NAS_NOTES.md`，本技能产出的周报同样遵守。动手前读记忆库的 `notes/README.md`：哪些笔记不纳入周报、周报的写作要求，以它为准。

## 第一步 · 定周

- 一周 = ISO 周，周一 00:00 到周日 24:00，用户本地时间。
- 默认：今天是周日就做本周；否则做上一个完整的周。用户给了周号（`2026-W48`）或说"本周 / 上周"就按用户的。
- 能运行命令就用 `date` 算；不能就按对话里已知的当前日期推算。

## 第二步 · 捞这一周的笔记

1. `read_memory_index` 读一遍索引，了解用户是谁、在忙什么（只作背景，不写进周报）。
2. 这一周可能跨两个月，对涉及的每个月调用 `list_memory_files(directory="notes/YYYY-MM")`。
3. 按文件名开头的时间戳（`YYYYMMDDTHHMMSS`，ljg-writes 是 `YYYYMMDDTHHMMSS==z`）筛出落在这一周里的笔记。`notes/weekly/` 里的周报不算输入。
4. 逐篇 `read_memory_file` 读全文。不要只看 summary 就下结论。
5. `notes/README.md` 规定不纳入周报的笔记：不读正文，不写进周报，只在"本周概览"里记一句"另有 N 篇未纳入"。
6. 一篇都没有：告诉用户这周没有笔记，不写周报。

## 第三步 · 读上周和更早

- 读上周的周报 `notes/weekly/{YYYY}-W{上周}.md`。没有就往前找最近的一篇；一篇都没有就在周报里写明"这是第一篇周报，没有对照"。
- 需要看长期走向时，再读之前 2–3 篇周报（只读周报，不重读旧笔记）。

## 第四步 · 分析

先自己把这周的笔记读成一张地形图，再动笔。要回答的问题：

1. **这周在想什么**：笔记分属哪几个主题？哪个主题占了最多心思？各用了哪些技能（追本、约束、秩、盲区……）。
2. **和上周比**：
   - 延续的问题：上周在想、这周还在想的。进展了还是原地转？
   - 新出现的问题：从哪儿冒出来的（哪篇笔记、什么触发）。
   - 消失的问题：上周很重、这周没提的。是解决了、放下了，还是在回避？只陈述证据，不替用户下结论。
3. **想法的变化**：同一个问题上，判断变了的地方。格式：上周说 X（引原句和链接）→ 这周说 Y（引原句和链接），变化的原因是什么。没有变化就不要硬找。
4. **反复出现的东西**：跨多篇笔记反复出现的前提、框架、措辞。它在帮用户看清，还是在挡住别的视角？
5. **互相矛盾的地方**：这周不同笔记之间结论打架的，并排列出来。
6. **下周最值得追的一个问题**：只给一个，说清为什么是它，以及用哪个 ljg 技能去追最合适。

要求：

- 每个判断都要落到具体笔记上，用 `[[notes/2026-11/文件名]]`（不带 `.md`）链接，方便在 Obsidian 里点开。引原句时加引号。
- 用用户的原话和原概念，不要换成自己的术语。
- 看到停滞或回避，照实说。
- 中文散文为主，必要处用短列表。全文 1,500–3,000 字。

## 第五步 · 写周报

文件：`notes/weekly/{YYYY}-W{ww}.md`（如 `notes/weekly/2026-W48.md`，周号两位）。

```markdown
---
title: 周报 2026-W48
type: note
summary: 一行：这周最主要的变化
skill: ljg-weekly
period: 2026-11-23 → 2026-11-29
tags: [weekly]
sources: 12            # 纳入的笔记数
---
# 本周概览
<笔记数、技能分布、主题分布；未纳入的笔记只记篇数>

# 这周在想什么
# 和上周比
# 想法的变化
# 反复出现的东西
# 互相矛盾的地方
# 下周最值得追的一个问题
```

- 同一周的周报已存在：先读它，再整篇重写（用户重跑通常是因为这周又多了笔记）。
- 调用：`upsert_memory_file(relative_path="notes/weekly/2026-W48.md", content=..., commit_message="weekly: 2026-W48", index_impact="none")`。
- 写入后 `read_memory_file` 读回核对。

## 第六步 · 回复用户

在对话里给 5–8 行摘要：最大的变化、下周要追的问题。末尾写 `已存：notes/weekly/2026-W48.md`。
